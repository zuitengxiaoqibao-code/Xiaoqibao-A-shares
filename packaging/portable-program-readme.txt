易数智算-A股观测台｜Windows x64 便携版

本压缩包只包含可运行程序，不包含行情数据库、新闻数据、缓存、日志、模型、导出文件或备份文件。
公开便携包不包含 API 密钥或个人配置，AI 功能需要自行配置。

使用方法：
1. 解压整个文件夹，不要只复制 exe 文件。
2. 双击 xiaoqibao.exe 启动程序。
3. 打开“本地运维”，执行“一键全面修复数据”，按页面进度完成数据下载、解压、校验和导入。
4. 修复完成后重新进入各菜单读取真实数据。

系统要求 Windows 10/11（64 位）和 Microsoft Edge WebView2 Runtime。
首次启动会初始化运行目录；数据补齐需要网络，耗时取决于数据量和来源可用性。
升级前完全退出旧版并备份持久目录，不要覆盖仍在运行的程序。
