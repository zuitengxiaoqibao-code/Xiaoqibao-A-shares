# Windows 便携成品

这里提供新版易数智算-A股观测台，面向 Windows 10/11 x64。

- 直接下载：同目录 XiaoQiBao-Portable-Windows-x64.zip，完整解压后运行 xiaoqibao.exe。
- 下载完整源码仓库的用户：进入 XiaoQiBao-Portable 文件夹，双击 xiaoqibao.exe，无需编译。
- 需要自行部署或修改：阅读根目录 README 中的源码部署和构建说明。

必须保留 _internal 和 web 文件夹。系统需要 Microsoft Edge WebView2 Runtime。

本成品不包含个人配置、API 密钥、数据库、新闻、缓存、日志、备份或模型权重。首次启动会创建运行目录；请在“数据设置”检查来源，在“本地运维”按需补齐数据，AI 需自行配置。

SHA256SUMS.txt 记录便携文件哈希；PUBLIC-DOWNLOAD.json 记录 ZIP 与 EXE 的校验信息。第三方许可文件位于便携目录 THIRD_PARTY_LICENSES。
