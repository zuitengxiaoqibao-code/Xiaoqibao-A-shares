# 小七宝 A 股观察台

面向新手的本地 A 股研究工具。选择一只已验证股票后，系统检查并补齐可获得的真实数据，再给出可追溯的确定性行动。主界面提供今日研判、A 股观察、首次涨停、新闻热点、风险提醒、历史复盘和数据设置七个入口；可转债使用独立入口、路由和选择状态。首次涨停在收盘后按估值、周/月线底部和回撤结构建立独立观察池，涨停当日只记录、不买入。

当前产品不保留纸面交易：没有模拟资金、模拟账户、模拟委托、模拟成交或模拟操作计划。历史数据库文件不会被主动删除，但新运行时不读取或写入这些旧表。本项目也不连接券商、不下单、不提供买卖价格、仓位或止损，不构成投资建议。

## 新手行动

- `wait` / 暂不参与：核心行情或趋势证据不足，等待数据或信号。
- `observe` / 加入观察：已达到最低研判要求，未发现确定性风险阻断。
- `avoid` / 回避：存在明确风险事件、异常指标或规则阻断。

行动卡展示结论、置信度、主要依据、主要风险、等待信号、重新判断条件、数据时间和来源覆盖。动作、数字和风险门禁由确定性程序产生；AI 只能解释冻结证据，不能修改结论或补造缺失数据。

任意已验证的 A 股都可以获得即时确定性研判，不要求先进入候选榜。候选资格只决定是否进入盘前、盘中和盘后账本，不会阻止单股观察卡生成；非候选股票不会生成价位、仓位或模拟方案。

候选卡展示最后真实交易日的冻结收盘价、近 5 日和近 20 日涨跌，并单独标注数据日；它不会把研判截止日或历史涨跌冒充盘中实时行情。实时价格和行情时间只在单股行动卡中展示。

盘前、盘中和盘后阶段使用后端统一调度状态。未到时间时显示 09:20、10:30、15:30 的计划生成时间；执行中、已完成、失败和到点未产出分别显示，不再把所有空阶段混成“没有记录”。交易日先由维护版上交所日历确认，再由本地真实日线和腾讯当日指数日期补充验证；日历覆盖范围外保持未确认，不按工作日猜测节假日。

## 数据补全

当前股票的实时研判会自动检查数据覆盖，缺失时显示来源级进度并触发幂等补全，完成后至多自动重新研判一次。历史复盘只使用截止时间内可见的数据，不会触发实时补全。

真实来源优先级如下：

- 实时行情与估值：腾讯行情。
- 日线与趋势：优先通达信 `mootdx`，不可用时回退百度 K 线。
- 基本面：通达信财务快照。
- 新闻与个股事件：已采集新闻和本地冻结事件仓储；只有已核验且关联标的的事件进入确定性依据。
- 热点与行业：通过保守的确定性词表生成规范化标签；已核验标签可进入依据，待核验标签只在信息流展示并明确隔离。
- 资金流：东方财富个股日级与盘中资金流快照；只作为支持或反方证据，不单独改变行动和置信度。
- 风险：基于行情、日线、基本面和已核验事件的确定性规则。

资金流不是核心研判分区：上游不可用时明确显示缺失，不用 `0` 或估算值代替。历史复盘提供固定 `5/20` 日双均线回测，使用 100 万元统一测算基准、次日开盘成交、佣金和滑点，展示收益、回撤、波动、胜率、成本、样本分段和市场阶段；它不连接模拟账户，也不影响实时行动。免费公开源可能限流、改版或暂时不可用，系统会保留上次成功快照并标记陈旧，或明确显示失败原因，不会用估算值冒充真实结果。可转债保持独立路由、独立条款、估值和风险指标；缺少成交额、纯债价值或行情授权时明确显示未知或不可用。

## 环境与启动

需要 Windows 10/11、Python 3.12、Node.js 22 或更新版本，以及 pnpm 10 或更新版本。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".\apps\api[dev]"
pnpm.cmd install
powershell -ExecutionPolicy Bypass -File .\scripts\dev.ps1
```

浏览器访问 `http://127.0.0.1:5173`。可按六位代码或已观察中文名称搜索；A 股选择写入 URL 并支持刷新、前进和后退恢复。进入可转债专区会移除 A 股 `symbol`。

默认运行数据固定写入项目根目录 `.runtime`，不受 API 从 `apps/api` 还是项目根目录启动的影响；需要隔离环境时可通过 `QIBAO_DATA_DIR` 指定绝对路径。

## 本地 AI 设置

在“数据设置”中可以管理本机通达信、券商通达信和同花顺安装目录，也可以保存 OpenAI 兼容 API 地址、模型和密钥。通达信目录会校验沪深 `vipdoc` 日线文件并按手动顺序优先使用；同花顺当前只检测安装状态，不会伪称已读取本地行情。密钥只写入被 Git 忽略的本地运行目录；读取接口只返回是否已配置及脱敏尾部，不返回、预填或记录完整密钥。清除配置需要显式操作。

保存后无需重启，单股行动卡、随后同步的新闻事件以及后续盘前、盘中、盘后阶段快照的补充解释都会读取最新设置。新闻热点已选择股票时只同步该 A 股；未选择时才执行全市场同步。历史事件如果只有降级解释，后续同步会按当前模型追加新解释，每次最多生成 10 条；旧解释不更新、不删除。盘前和盘后配置变化都会在相同冻结证据上追加新快照，不覆盖旧结论。盘中仍先由确定性行情规则计算，只有准备追加新的可用建议变化时才对整批变化调用一次模型；无变化轮询、阻断和空恢复不调用。盘后先由确定性程序冻结结果归因、撤回状态和次日观察，再用一次模型调用追加只读解释。模型未配置或调用失败时保留确定性证据摘要并明确标记降级，不用模型输出改写行动、置信度、数值或风险门禁。

“数据设置”里的来源授权区按资产域分开管理 A 股和可转债的公开来源。转债诊断遇到未授权来源时，会引导到这里完成授权和声明确认；未确认前不会请求对应来源，也不会用空数据代替真实结果。

也可使用环境变量提供配置：

```powershell
$env:QIBAO_AI_BASE_URL = "https://your-compatible-endpoint/v1"
$env:QIBAO_AI_API_KEY = "your-api-key"
$env:QIBAO_AI_MODEL = "your-model"
```

三项必须同时有效才会请求模型。未配置、超时、HTTP 错误、非法输出或证据引用越界都不会影响确定性行动。

## Kronos 价格路径证据（可选）

“首次涨停 → 量化分析”可接入 [Kronos](https://github.com/shiyu-coder/Kronos)，使用本地真实 A 股日线生成未来 5 至 20 个交易日的价格路径情景。该面板只显示中位路径、上下分位区间、下行概率和路径分歧度，不直接改变规则结论，也不产生自动买卖指令。

Kronos 默认关闭，未配置时页面会明确显示“模型未启用”，规则、市场情绪和回测功能仍可使用。系统不会自动下载模型权重，也不会用随机曲线填补缺失结果。启用前需自行克隆官方仓库、按其说明安装 PyTorch 与依赖，并准备本地模型权重或可访问的 Hugging Face 模型：

```powershell
$env:QIBAO_KRONOS_ENABLED = "true"
$env:QIBAO_KRONOS_REPO_PATH = "D:\path\to\Kronos"
$env:QIBAO_KRONOS_MODEL = "D:\path\to\Kronos-mini"
$env:QIBAO_KRONOS_TOKENIZER = "D:\path\to\Kronos-Tokenizer-2k"
$env:QIBAO_KRONOS_DEVICE = "cpu"
$env:QIBAO_KRONOS_LOOKBACK_BARS = "250"
$env:QIBAO_KRONOS_SAMPLE_COUNT = "20"
```

也可以把模型和 tokenizer 配置为 Hugging Face 名称，但首次加载需要网络可用。模型在第一次预测请求时延迟加载，不会阻塞 API 启动。

## 调度与备份

后台仍保留数据采集、风险、合规、审计、调度和备份服务，但不再以部门名称作为用户导航。每日任务按已确认交易日运行：盘前 09:20，盘中 10:30、13:30、14:30，盘后 15:30；失败任务最多尝试三次，重启后补查最近七天到期但未完成的槽位。`exchange-calendars` 需要随项目依赖定期更新；超出其日历覆盖范围时系统回退到真实市场信号，不自行推断。

备份会生成 SQLite 在线快照、DuckDB checkpoint、Parquet 副本和 SHA-256 清单。当前部署须保持单个 API 进程。恢复必须发布到新目录，不能覆盖正在使用的 `.runtime`：

```powershell
..venv\Scripts\python.exe .\scripts\restore_backup.py `
  backup-20260714T133107Z-e1148658 `
  .\.runtime-restored
```

当前交付边界和后续数据工作见 [路线图](docs/roadmap.md)。

## Windows 便携版

便携版不需要安装，也不需要 Node.js 开发服务器。构建命令：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build-portable.ps1
```

产物位于 `dist\XiaoQiBao-Portable`。双击 `xiaoqibao.exe` 启动；`_internal` 和 `web` 是程序运行文件，`config`、`data`、`news`、`cache`、`logs`、`models`、`exports`、`backups` 是可独立管理的本地目录。请移动整个目录，不要只移动 EXE。

该产物不是安装程序，不写注册表、不申请管理员权限。程序图标来自 `packaging\assets\xiaoqibao.png`，构建时使用对应的多尺寸 Windows 图标 `xiaoqibao.ico`。便携版统一使用 `data` 保存结构化数据，运行缓存写入独立 `cache`，本地行情目录配置写入 `config\data-sources.json`。程序默认自动发现本机行情软件；可选的 `127.0.0.1:17709` 通达信实时桥接默认关闭，关闭时不会访问该端口。若检测到早期版本的 `data\legacy`，程序会在启动前把无冲突数据提升到 `data`；同名冲突文件保留当前版本，并将早期文件归档到 `backups\previous-data-*`，不会静默覆盖或删除用户数据。
