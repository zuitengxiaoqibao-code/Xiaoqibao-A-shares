# 股票监控可视化

## 目标

按照参考风格制作高相似度、动态、有人性化交互的网页版股票监控大屏，并逐步完善数据看板。

## 用户偏好证据

- 页面不能只是静态展示，要有动效和实时感。
- 数据来源必须可解释，不能出现无法说明的价格或虚假数字。
- 排行类模块希望信息密度高，例如涨速雷达需要更多可见行。

## 最近状态

替换模块后曾因旧 DOM 元素仍被直接写入导致全站更新中断；已通过存在性判断和图表空判断修复。页面和速度雷达接口曾验证可用。

## 风险

兜底数据必须明确标识，不能被误认为真实行情。
