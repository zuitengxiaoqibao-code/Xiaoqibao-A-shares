# 财经信息爬虫

## 目标

持续抓取国内外实时财经财政信息，支持自定义抓取频率、新信息提醒、翻译、证据和事件归档，并可部署到国外服务器。

## 最近确认状态

- 本地版本曾更新到 V2026.7.13.22。
- 普通新闻、翻译、可读性、证据、事件档案和盘面观察都有保留期和硬上限。
- 失败投递队列最多保留 7 天、硬上限 500 条。
- SQLite 主库、WAL、SHM 均计入体积监控；WAL 达到 64 MB 触发轻量检查点。
- 每日推荐清理、每周压缩，达到保护线时升级为深度清理。
- 最近报告 80 项测试、编译、前端脚本和中文编码检查通过；源码已安全上传，未更新服务器或重新打包 EXE。

## 决策

首页只读最新有限数据，不扫描全库。重要事件进入事件档案/证据快照，普通明细严格限量。
