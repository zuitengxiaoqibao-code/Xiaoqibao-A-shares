# 项目记忆归档

本目录保存与“一树-A股观测台 / 小七宝 A 股项目”直接相关、已经脱敏的长期项目记忆，供后续开发者恢复设计背景、历史决策、验证证据和数据真实性边界。

归档范围包括：

- `金融财经.md`：当前项目的主要实现、发布和验收记录。
- `一树-A股观测台.md`：同一产品路线的长期决策与迭代记录。
- `A股转债量化.md`：A 股与可转债量化研究的早期设计和实现依据。
- `财经信息爬虫.md`、`股票智算.md`、`股票监控可视化.md`、`API数据页面.md`：项目合并前的相关能力背景。

以下内容不会进入公开仓库：用户个人偏好记忆、其他无关项目记忆、每日跨项目活动记录、历史备份副本，以及任何 API Key、Token、密码、Cookie、Webhook、私钥、数据库凭据或可还原的认证片段。

项目运行数据、行情数据库、新闻、缓存、日志、模型、导出和备份同样不属于源码归档。真实数据应在安装后通过“本地运维 → 一键全面修复数据”补齐。
