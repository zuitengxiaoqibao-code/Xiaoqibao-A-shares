# A 股观察台路线图

## 当前已交付

- 九个新手入口（含“信息总览”“首次涨停”“量化分析”）和独立可转债入口。
- “信息总览”以单一聚合接口展示市场情绪、五指数行情、上证分时异动、30 条实时资讯、热门板块和成分股联动；各来源独立降级，5 秒刷新，页面隐藏时暂停请求，不使用随机或静态行情。
- 任意已验证 A 股的 `wait`、`observe`、`avoid` 确定性研判。
- 实时数据覆盖检查、来源级补全进度、手动重试和自动同步开关。
- 历史截止时间约束、三阶段结论回看、A 股与可转债状态隔离。
- 本地 OpenAI 兼容设置、密钥脱敏和 AI 失败降级。
- 真实行情、日线、基本面、新闻事件、行业和风险来源的部分降级。
- 可审计的东方财富个股资金流快照；上游不可用时明确缺失，不推算、不补零。
- 历史复盘内的真实双均线回测，包含成本、回撤、波动、样本分段和市场阶段归因。
- 候选与趋势证据区分研判截止日和最后真实交易日；候选卡展示冻结收盘价及 5 日、20 日涨跌。
- 盘前可用维护版上交所日历确认当天交易日；三阶段统一展示计划、执行中、完成、失败和到点未产出状态。
- 已移除纸面资金、账户、委托、成交和模拟操作计划的产品入口及运行时 API。
- 通达信日线与财务查询在单次操作内遍历已配置节点，空响应、连接异常和节点错误都会继续故障转移；所有节点无数据时明确回退百度 K 线并保留逐节点尝试记录与实际来源。
- 任意已验证 A 股都有独立即时确定性研判；候选榜只负责三阶段账本资格，非候选不生成价位、仓位或模拟方案。
- 盘中行情缺失、过期或合规未放行时持久化空的阻断快照；阻断态不生成建议，也不会把数据中断误判为候选移除。午间休市只冻结上午收盘前三分钟内的同日最后行情，13:00 后恢复常规三分钟新鲜度门禁；数据恢复时即使动作未变化也会写入就绪快照。
- 盘中阻断快照保存行情缺失、质量异常、时间无效、行情过期、风险不可用、合规不可用或合规未放行等确定性原因；新手时间线明确解释本轮为什么没有新判断，并在存在历史结论时仅保留最近一次已验证判断，不把旧判断冒充本轮结果。
- 新闻生产装配使用保守的行业与热点词表；已核验标签进入证据，待核验标签只进入信息流，不改变动作、置信度或风险门禁。
- A 股基础证券目录支持低频东财分页同步，并在连接中断时回退巨潮官方证券清单；同步结果必须至少包含沪深两市且不少于 4000 只，单交易所或明显不完整结果不会覆盖当前活跃目录。当前活跃目录与历史观测分离，名称搜索不会把过期目录当作当前标的。
- “今日研判”现以九因子 A 股市场情绪仪表盘为准：波动率情绪 15%、成交活跃度 15%、价格强度 10%、风险偏好 10%、市场广度 15%、涨跌停情绪 15%、赚钱效应 10%、板块扩散情绪 5%、风格风险偏好 5%；覆盖率不足 70% 时不显示假分数。公式版本为 `a-share-sentiment-v2`，每个分项保留原始指标与证据；盘前/盘中/盘后仍使用冻结快照和明确的数据新鲜度状态。
- 可转债市场级发现池支持低频同步、条款/行情/估值缺口标记和资格门禁；未完成诊断的标的不进入观察候选。
- 个股新闻同步保留查询标的作为确定性关联上下文；无代码标题也能进入对应 A 股的有效新闻证据，全市场同步仍保持隔离。
- 本地 AI 设置无需重启即可同时用于单股行动卡、新同步新闻和盘前、盘中、盘后阶段快照的补充解释；历史降级新闻按当前模型每次最多追加升级 10 条，盘前和盘后配置变化追加新快照，既有记录保持不可变。盘中只在确定性程序准备追加新的可用建议变化时对整批变化调用一次模型，无变化轮询、阻断和空恢复不调用。盘后结果归因、撤回状态和次日观察由确定性程序冻结，模型每轮只调用一次并追加解释；模型不可用时不降低确定性决策状态。
- 资金流同步支持东方财富同源日级备用端点；分钟端点异常时保留日级快照并明确标记部分可用，不补零、不改变动作门禁。
- 阶段新闻依据只展示证据窗口内的相关已验证事件，默认三条并可展开；盘中建议用证据类型替换旧行情，只保留最新盘中行情与基线证据。变化流按新到旧默认展示三个折叠版本，手机端先展示当前判断再展示审计历史。
- 盘中行情新鲜度按研判范围读取真实轮询成功时间：单股使用焦点轮询，全市场使用全域轮询；建议内容没有变化时不再误报链路过期，真正超过动态有效阈值时明确显示对应范围、最近成功时间和旧建议保留规则。盘前、盘后、历史和休市快照不套用实时过期提示。
- 腾讯实时行情改为批量请求，并只对缺失或无效股票定向重试一次；重试后仍不完整时整批失败，焦点与全市场错误分开保存。新手界面只解释当前观察范围的故障原因、连续失败次数和自动重试状态，非实时阶段不显示实时故障。
- A 股盘中热点使用独立的同花顺强势股题材归因源，严格解析真实的代码、名称、交易日和题材标签，不补造价格、涨幅、成交额或换手率。热点以追加式 `market_hotspot` 证据进入既有事件仓库，授权、同步错误和运维任务均与东方财富新闻及腾讯行情隔离；10:30、13:30、14:30 和手动盘中研判会在决策前尝试刷新，失败不阻断确定性流程。新手新闻页提供独立“同步热点”、题材标签、来源时间和已核验热点数。
- 通达信节点故障转移统一由应用控制，关闭 mootdx 内层重复重试后，五节点空响应可快速转入百度 K 线备用源；百度日线按完整批次校验必需字段、行宽、日期唯一性和 OHLC 边界，坏行不会部分入库。通达信财务非空响应仍须至少包含一个可用观测字段，纯元数据不会被当作已验证基本面。
- 来源健康观测已接入运维仓储和新手“数据设置”：按来源、操作和节点记录成功率、耗时、最近成功/失败、错误类型及百度最新交易日/字段校验；展示只解释数据链路状态，不改变研判、动作、置信度或风险门禁。
- 东方财富资金流的日报、分钟端点也写入同一来源健康事件流；分钟端点失败时保留日报快照，并在健康记录中明确错误类型、样本数和字段校验。
- 资金流刷新失败原因会跨后续准备检查保留，并贯通到驾驶舱诊断；当前刷新失败会覆盖旧资金流快照的可用状态，避免旧快照把链路故障伪装成当前可用。
- 精确六位 A 股代码搜索始终重新请求并校验实时行情，只有代码一致且行情有效时才返回 `quote_quality=ready`；名称搜索继续使用已观测目录，避免旧目录名称冒充当前可验证标的。
- 盘后当前建议展示按盘前/盘中最新有效的股票与周期去重；旧复盘卡仍保留在追加式历史和变化证据中，避免新手工作台重复堆叠同一股票的历史版本。
- append-only 日线的同日修订版本先按最新入库时间去重，再进行历史窗口排名；同日重传不会减少可用历史根数。
- 可转债发现池明确区分未诊断、数据不可用、风险排除和可观察四种状态；批量诊断失败原因转换为新手可读说明，不再展示内部错误码。

## 近期工作

1. 继续扩展受控策略 DSL 的窗口函数、策略版本审批和 walk-forward 样本外证据，不开放任意 Python 执行。
2. 将监控中心的价格、成交、策略、新闻和风险规则接入更多实时快照，持续验证 Edge TTS 与飞书通道的独立重试和冷却去重。
3. 扩大已核验个股事件与行业覆盖，积累盘后冻结报告与候选结果，以真实远期收益校准策略而不是展示伪概率。
4. 补齐可转债专属行情、条款与风险指标，继续与 A 股状态隔离。

## 产品边界

纸面交易不是后续产品路线。系统不恢复模拟账户、模拟订单或模拟成交，也不连接券商和自动交易。任何未来数据源都必须明确来源、观察时间、失败原因和授权边界；AI 始终只做解释，不能生成数字或改变确定性行动。
