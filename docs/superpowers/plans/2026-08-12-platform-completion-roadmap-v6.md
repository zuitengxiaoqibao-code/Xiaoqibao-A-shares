# 一树-A股观测台完整完善路线 v6.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不增加重复菜单和模拟数据的前提下，完成速度、真实性、事件、量化、公司研究、图形语义、数据复用和便携体积八项系统完善。

**Architecture:** 复用现有缓存、快照、性能采样、公司研究分块任务和证据账本；新增能力必须落到独立模块，并由页面组合使用。实施顺序遵循数据底座依赖：先消除重复请求和重复计算，再统一证据与事件契约，最后深化分析、视觉与发布治理。

**Tech Stack:** Python 3.12、FastAPI、DuckDB/SQLite、React 19、TypeScript、ECharts、Vitest、pytest、PyInstaller、pywebview。

## Global Constraints

- EXE 是唯一用户交付和查看入口。
- 不生成模拟行情、模拟事件、模拟候选、模拟财务或模拟专业接口字段。
- 缓存必须明确标注时间和状态，不能冒充实时数据。
- 红涨绿跌；事件归属色必须避开涨跌色和价格主线色。
- 不关闭、重启或控制通达信，不控制鼠标或桌面。
- 不关闭用户正在运行的观测台；运行中构建只允许安全暂存并在下次启动应用。
- 保留 `config/data/news/cache/logs/models/exports/backups` 八个持久目录。
- 中文文件使用 UTF-8 安全编辑，最终运行乱码扫描、全量测试、生产构建、EXE 重建与真实发布数据 smoke。

### Phase 1: 数据加载与请求合并

- [x] 建立只读 GET 请求单飞层：相同 URL/headers/credentials 的同时请求共享一次底层 fetch。
- [x] 每个调用者保留独立 AbortSignal；一个调用者取消不能中止其他调用者。
- [x] 请求完成或失败后立即释放，不缓存错误，不改变 HTTP 语义。
- [x] 接入信息总览、个股观察、行情快照、量化分析和公司研究轮询读取。
- [x] 记录请求合并命中次数、底层请求数和节省耗时，接入现有性能仪表盘。
- [x] 对全市场扫描、板块快照和公司研究各区块建立后端同键任务合并，避免同一时刻重复读取 DuckDB/通达信。
- [x] 验收：缓存首屏小于 300ms；信息总览最新读取目标小于 1 秒；个股观察目标小于 800ms；公司研究首屏小于 1 秒、完整补齐目标小于 3 秒；页面切换无整页遮罩。

### Phase 2: 字段级真实性证明

- [x] 定义统一字段证据信封：值、来源、采集时间、交易日、原始字段、实时/缓存/盘后/缺失/冲突状态、覆盖率、推算标志、公式和证据引用。
- [x] 对市场总览、个股观察、量化和公司研究的关键数字逐步迁移。
- [x] 多来源冲突时公开主采用值、备选值、差异、采用理由及是否影响结论。
- [x] 证据详情按需展开，不让证据元数据压缩主界面。
- [x] 缺失字段保持缺失，任何评分都公开有效分母与降级原因。

### Phase 3: 统一事件体系

- [x] 定义政策宏观、行业板块、公司公告、业绩财务、资金龙虎榜、价格成交异动、风险事件、传闻待核验八类事件。
- [x] 每条事件记录影响对象、板块、方向、强度、可信度、持续时间、价格反映程度和后续观察指标。
- [x] 新闻、公告、热点、盘中异动与 K 线共用事件标识和去重规则。
- [x] 增加紧凑图例，明确事件颜色代表归属，不代表涨跌。
- [x] 同日事件稳定，只追加新真实事件；跨交易日重置。

### Phase 4: 量化严格验证

- [x] 训练、验证、样本外按时间顺序隔离，禁止样本外继续调参。
- [x] 增加滚动回测、前视偏差、幸存者偏差、停牌、涨跌停不可成交、佣金、印花税和滑点处理。
- [x] 统计分市场风格胜率、信号衰减、最大连续亏损、最大回撤、Sharpe、EV 和盈亏比。
- [x] 实盘影子账本继续使用冻结输入，并增加预测校准与漂移状态。
- [x] 候选统一输出“触发成立 / 等待确认 / 不具备条件”，公开入选、未满足、触发、失效和覆盖率证据。

### Phase 5: 公司研究闭环

- [x] 固定十段研究结构：商业模式、行业空间、财务趋势、利润质量、竞争地位、估值分位、未来催化、反方风险、失效条件、核验清单。
- [x] AI 仅基于冻结真实证据总结和反驳，不补全缺失事实。
- [x] 增加研究版本对比，展示相较上次变化的结论、数据和来源。
- [x] 六区块后台增量更新继续保留，单块失败不清空完整缓存。
- [x] 同一股票同一交易日复用已有任务和区块结果。

### Phase 6: 全站图形语义统一

- [x] 建立共享图形规范和令牌：红涨绿跌、黄橙红风险、青色完整度、灰色缺失、独立事件归属色。
- [x] 资金流统一零轴柱状图，趋势统一 K 线/折线，构成统一堆叠条/矩形树图，排名统一横条，单评分统一半圆仪表盘。

- [x] 建立布局回归测试，防止最大化、窄屏和数据稀疏时出现大块无意义留白。
- [x] 字号不得低于 12px，核心数据和事件标注保持可读。
