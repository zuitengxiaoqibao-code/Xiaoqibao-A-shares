# 首次涨停量化分析仪表盘设计

## 目标

在“首次涨停”下增加独立的“量化分析”二级菜单和页面。页面面向新手提供可追溯的量化信息，不替代现有规则评审，也不生成自动交易指令。

## 页面结构

- 路由：`/first-limit-up/quant-analysis`。
- 左侧导航：“量化分析”缩进显示在“首次涨停”下方。
- 页头：当前标的、数据状态、数据截止时间、切换标的控件。
- 左上：ECharts 盘中 TICK 分时图，价格折线和成交量柱共用时间轴；覆盖实时价格和涨跌幅。
- 右上：信号引擎，展示 VOL、SCORE、胜率、赔率、风险、仓位、EV 七项指标。
- 左下：因子雷达，展示估值、底部位置、回撤结构、盘整程度、趋势和量能等可验证因子。
- 右下：回测权益与回撤图，展示样本数、最大回撤、样本外结果和警告。

## 数据原则

- TICK 数据来自盘中轮询归档，不用随机数生成走势。
- SCORE 和首次涨停规则状态来自现有 `FirstLimitUpBoard`。
- 胜率、赔率、波动率、最大回撤和权益曲线来自现有回测接口。
- 无法由现有证据得到的风险、仓位和 EV 显示“待验证”或采用明确标注的规则映射，不冒充统计结果。
- 数据缺失、过期、来源失败均在对应象限内说明，不用默认值掩盖。

## 视觉系统

- 背景：`#06080d`；面板：`#0a1018`；边线：`#243047`。
- 主强调：金色 `#f4c76a`；行情：青色 `#34d6ff`；风险：洋红 `#ff5c8a`；可用：绿色 `#50e3a4`。
- 标题优先使用 Orbitron，数据使用 JetBrains Mono；网络字体不可用时退化到本机等宽字体。
- 页面只保留轻量扫描线、标题脉冲和 Hover 边框辉光；遵守 `prefers-reduced-motion`。
- 宽屏为 2×2 四象限，中屏保持双列，小屏变为单列。

## 验收标准

- 侧边栏能进入量化分析并正确同步浏览器路径。
- 至少一只首次涨停候选时可切换标的。
- ECharts 正确创建并在卸载时销毁实例。
- 无 TICK、无回测或部分指标缺失时有清晰空态。
- 页面不显示伪造实时值，不出现 `NaN` 或 `Infinity`。
- 前后端聚焦测试、完整前端测试和生产构建通过。
