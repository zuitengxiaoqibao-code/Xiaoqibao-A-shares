# 一树-A股观测台全站证据契约重构设计

## 目标

把现有一级菜单和信息总览 50 个子菜单重构为职责清晰、数据真实、状态可追溯、展示方式与数据语义匹配的本地 A 股研究软件。所有页面以便携 EXE 为唯一用户入口，不生成独立网页交付。

## 核心原则

1. 菜单名称必须与实际数据能力一致。
2. 原始字段、确定性派生、观察性合成和 AI 解释必须明确区分。
3. 缺失字段保持 `partial`、`stale`、`unavailable` 或 `error`，不得用零值、随机值或无关字段代理。
4. 全市场统计必须使用完整横截面；代表股票和强势板块样本必须明确标注样本范围。
5. 红色表示上涨或改善，绿色表示下跌或风险，灰色表示不可用。
6. 正文不低于 13px，辅助标签不低于 12px。
7. 后台刷新不得清空现有页面、遮挡整页或引起布局跳动。

## 证据契约

每个菜单必须登记以下字段：

- 用户问题：页面回答什么问题。
- 最低证据：生成结论至少需要哪些真实字段。
- 计算合同：公式、窗口、样本、阈值和版本。
- 展示合同：最适合该数据关系的图表、表格或时间线。
- 状态合同：数据完整、部分、过期、不可用和错误时如何显示。
- 刷新合同：盘中、盘后、日级或按需刷新频率。
- 跳转合同：从市场发现页进入哪个深度工作台。

## 一级菜单职责

| 菜单 | 唯一职责 |
|---|---|
| 信息总览 | 全市场发现、异常定位和深度页面入口 |
| 今日研判 | 盘前、盘中、盘后已生成研判的汇总与变化 |
| 个股观察 | 单股实时量价、事件 K 线、风险和触发状态 |
| 公司研究 | 2-3 年基本面、财务、估值、竞争、催化和反方审查 |
| 首次涨停 | 盘后首板规则池及涨停后回撤观察 |
| 量化分析 | 市场风格、策略路由、触发、Kronos 和回测 |
| 新闻热点 | 新闻采集、分类、证据链和 A 股关联 |
| 风险提醒 | 市场、个股、事件、数据和策略五层风险 |
| 历史复盘 | 研判归因、策略回测、参数对比和失效统计 |
| 数据设置 | 本地数据源、目录、健康状态、AI、语音和缓存 |
| 可转债 | 独立的转债行情、条款、估值、正股和风险体系 |

## 信息总览语义族

### 竞价与异动

`盘中异动`显示真实事件时间线；`异动语音播报`管理已验证事件的语音队列；`隔夜单/抢筹`在未取得委托队列前显示为高开缺口；`竞价封单`仅在取得真实封单字段后展示封单金额；`竞价异动`比较开盘缺口和当前确认；`竞价选股`展示逐项规则闸门；`开盘啦`改为开盘检查；`个股异动`使用逐股量价检测；`异动提醒`是用户规则收件箱；`异动统计大全`只统计持久化异动事件。

### 涨停生态

`涨停板`展示严格封板事实；`昨涨停`展示上一交易日名单的今日反馈；`跌停板`展示风险扩散；`炸板`展示触板回落；`首板梯队`展示当日首次封板；`连板梯队`按真实连续高度分层；`连板表现`统计昨日梯队的晋级、断板和收益；`龙头梯队`按板块角色和容量分层；`龙头晋级`展示前一阶段到当前阶段的迁移；`板块涨停`展示板块内扩散；`涨停复盘啦`改为涨停复盘。

### 题材、板块与资讯

`AI+题材`只解释已经取得的题材证据；`板块精选`使用多因子过滤；`板块赛道`展示多窗口轮动；`强度风口`展示盘中加速与扩散；`题材库`保存题材档案；`题材挖掘`检测证据增长；`热点播报`展示按时间排序的 A 股资讯；`热点解读`展示新闻到题材到股票到行情的证据链；`概念叠加`展示股票与题材矩阵；`非研产业库`改为产业链资料库；`投资日历`优先使用官方事项日期。

### 排名与筛选

`情绪周期`只有在具备历史阶段序列后保留周期名称；`人气榜`改为观察热度榜；`七大人气榜`改为七维活跃榜；`百日新高`和`百日新高趋势`使用完整历史窗口；`区间统计`要求明确起止交易日；`放量突破`、`突破前高`、`低位放量`展示公式、窗口和逐股结果；`AI+选股`执行规则先筛选、AI 后解释；`问财选股`在未接官方语义接口前改为条件选股；`复盘统计大全`汇总完整市场结构。

### 资金与席位

`游资追踪`展示席位历史档案；`游资动向`展示当日席位方向；`龙虎榜`展示股票和席位明细；`主力大单监控`必须取得逐笔方向或真实大单流；`板块资金动图`必须取得板块净流入时间序列。后两项在字段不足时只显示紧凑数据状态，不生成资金结论。

### 个股入口

信息总览中的`个股详情`改为`个股快览`，只提供市场发现后的快速信息和跳转；完整研究留在个股观察和公司研究。

## 展示合同

- 单一状态：带阈值、时间和覆盖率的状态条或仪表。
- 横截面：热力图、象限、分布或红绿零轴图。
- 时间变化：分时、K 线、资金曲线或事件时间轴。
- 筛选结果：可排序表格、状态标签和迷你 K 线。
- 资金方向：零轴柱图、买卖对照或席位关系图。
- 新闻题材：标签流、事件链和扩散时间轴。
- 缺失数据：紧凑说明缺少字段、影响和补齐方式，不渲染空图。

## 数据刷新架构

- 1-5 秒：当前行情和已选股票触发证据。
- 15-30 秒：板块横截面、异动检测和量化候选触发。
- 60 秒：新闻、热点和题材证据。
- 盘后一次：涨跌停、突破、连板和历史筛选。
- 按需：公司研究、Kronos、研报、龙虎榜席位和回测。
- 所有链路使用缓存先显示、后台静默更新；刷新失败保留上次完整数据。

## 阶段交付

1. P0 数据真实性：修复错误状态、样本口径、历史新鲜度、默认入口和误导名称。
2. P1 高频页面：重构总览首页、情绪、涨停、板块、异动和新闻工作区。
3. P2 数据补全：逐笔大单、板块资金、官方日历、语义搜索、研报和一致预期。
4. P3 深度工作台：公司研究、量化分析、风险提醒和历史复盘。
5. P4 性能验收：分频刷新、预加载、渲染稳定、全量测试和便携 EXE 烟测。

## 验收标准

- 冷启动首页可见 P95 不超过 3 秒。
- 缓存首屏不超过 500ms，已加载页面切换不超过 100ms。
- 后台刷新不出现整页遮罩和布局跳动。
- 所有菜单都有独立证据契约和状态合同。
- 不使用成交额代替净流入，不使用新闻发布时间代替官方事项日期。
- 不把代表股票或 12 个强势板块称为全市场完整榜单。
- 每个合成分展示公式、时间、覆盖率和版本。
- 没有数据时不生成模拟值、空图表或确定性结论。
