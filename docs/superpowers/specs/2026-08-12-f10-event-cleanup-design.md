# F10 事件清洗与可读决策卡片设计

## 目标

公司研究页只展示可核验的公司事件，去除通达信 F10 页眉、目录、表格边框和空栏目；财务字段按明确字段分别解析，禁止把营业收入与净利润两个数值拼成利润区间。

## 数据边界

- 原始来源仍为通达信 F10 和已接入的真实事项源。
- 不补写未经来源支持的事实，不调用模型生成数值。
- 影响判断与后续观察采用确定性规则，无法判断时明确显示“影响待确认”。
- 原始证据保留在折叠区，但先删除无意义的页眉、目录与表格边框。

## 后端方案

1. 在普通事件切分前识别财务快照，分别提取报告期、营业收入、营业收入同比、净利润和净利润同比。
2. 财务快照合并成一条“季度经营数据”事件，摘要只陈述明确字段。
3. 普通事件按项目符号和换行切分，不再按竖线拆散表格单元格。
4. 过滤 F10 股票页眉、栏目目录、空栏目和纯表格字段。
5. 资金类标题按解禁、回购、减持、定增、质押、融资等具体语义命名。

## 前端方案

每条事件卡片固定展示：

- 发生了什么：来源中的可核验事实。
- 影响判断：基于事件类型和方向的机械解释。
- 后续观察：明确下一步需要核验的公开字段。

顶部结论优先显示最重要风险和最重要正向事实；中性或证据不足事项不强行定性。默认显示三条，其余折叠，原始证据继续折叠。

## 视觉规则

- 正向事实使用 A 股红色。
- 风险使用黄橙色，避免与 A 股下跌绿色混淆。
- 中性与待确认使用蓝青色。
- 卡片采用信息块而非表格线，正文保持可读字号与自然换行。
