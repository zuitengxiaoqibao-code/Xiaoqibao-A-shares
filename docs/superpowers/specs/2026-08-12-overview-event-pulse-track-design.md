# 信息总览事件脉冲轨道设计

## 目标

将上证指数分时图中难以阅读的竖排事件文字替换为清晰的科技终端式事件脉冲轨道，同时保留真实异动与分时价格的时间关联。

## 交互结构

- 主图只显示短编号、发光交点和细引导线，不显示竖排标题。
- 图表上方使用两层事件轨道，编号按时间顺序排列。
- 同一分钟落点的多条事件合并为一个 `+N` 聚合标记，避免重叠。
- 选中事件显示金色光环、实线引导和竖向十字指示线。
- 图表上方增加选中事件玻璃态摘要卡，展示时间、完整标题、方向和关联题材。
- 右侧异动记录使用相同编号与方向颜色；点击后与图中选中状态同步。

## 数据边界

- 只使用现有真实 `minute_series` 和 `anomalies`。
- 超过 90 秒无法匹配真实分钟点的事件不落图。
- 聚合只改变显示，不改变事件数量或内容。
- 正向红色、负向绿色、中性蓝色、待核验灰色；金色只表示当前选中，不表达涨跌。

## 可读性与动效

- 编号至少 12px，摘要正文至少 13px。
- 发光和脉冲使用克制动画，并遵守 `prefers-reduced-motion`。
- 未来尚无分时数据的时段保持空值并降低视觉权重，不生成虚假价格。
- 小屏改为单列布局，事件轨道允许横向滚动，不压缩到不可读。

## 验收

- ECharts 配置不再包含竖排中文标签。
- 相邻事件编号不重叠，同一分钟事件出现 `+N`。
- 选中事件在图、摘要卡、右侧列表三处一致。
- 全量测试、生产构建、UTF-8 扫描、便携 EXE 构建和真实数据烟测通过。
