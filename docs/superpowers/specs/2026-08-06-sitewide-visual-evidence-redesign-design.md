# 一树 A 股观测台全站可视化与证据可信度设计

## 目标

建立一套适用于信息总览、今日研判、个股观察、公司研究、量化分析、首次涨停、新闻热点、复盘和可转债页面的统一可视化系统。页面优先回答“发生了什么、证据是什么、数据有多新、下一步观察什么”，而不是用静态数字或装饰性图表填充空间。

## 已确认的参考图形规则

| 数据语义 | 采用图形 | 适用页面 | 颜色规则 |
| --- | --- | --- | --- |
| 排名、强弱、覆盖率 | 横向条形图 | 热门板块、候选池、研究维度 | 红=上涨/改善，绿=下跌/恶化，结构排名用蓝/金 |
| 资金流向与净额 | 零轴柱 + 多线叠加 | 今日研判、个股观察、主力大单 | 正值红，负值绿；均线和基准使用青/紫 |
| 营收、利润、现金流趋势 | 柱线双轴图 | 公司研究、财务诊断 | 金融数值按事实显示，趋势改善红色，恶化绿色 |
| PE/PB/分位数历史 | 双轴时间序列 | 公司研究、估值观察 | 估值主线红，分位线灰；缺口断线不补值 |
| 单因子连续值 | 单线趋势图或 sparkline | 波动、情绪、换手、量比 | 方向字段遵循红涨绿跌，状态字段使用青/金 |
| 维度对比 | 雷达图 | 综合能力、策略因子 | 仅比较同一口径；缺失维度不绘制为 0 |
| 分类组成 | 饼图/环图（不超过 6 类） | 行业、产品、地区、资产负债 | 结构色使用蓝/青/金/紫，不把结构色误作涨跌 |
| 年月收益表现 | 热力矩阵 | 行情涨跌、复盘、历史表现 | 红色正收益、绿色负收益、灰色无数据 |
| 风险与亮点 | 标签组 + 风险条 | 公司研究、新闻、今日研判 | 风险红、正向红、观察金、未核验灰 |
| 评分与行业位置 | 环形仪表 + 横向进度条 | 公司研究、量化分析、市场情绪 | 仪表仅表示评分或覆盖度，明确注明不是收益概率 |
| 资产负债/层级构成 | treemap/面积映射 + 明细表 | 公司研究 | 蓝/青为构成色，黄色仅表示待核验或选中 |
| 价格与事件 | K 线 + 编号锚点 + 横向事件索引 | 个股观察、量化分析 | K 线红涨绿跌；事件方向独立标色并带证据状态 |

## 统一数据可信度契约

所有图表必须接收带状态的数据，不允许组件自行猜测或填充：

```ts
type EvidenceState = {
  status: "ready" | "partial" | "stale" | "unavailable" | "error";
  source: string;
  observedAt: string | null;
  coverage: number | null;
  warnings: string[];
};
```

- `ready`：完整字段、来源和观测时间可追溯。
- `partial`：部分字段缺失，图形只绘制有效点，并显示覆盖度。
- `stale`：展示最近缓存，同时显示缓存时间和过期时长。
- `unavailable`：只显示解释性空态，不显示 0、50、100 或伪造走势。
- `error`：显示具体失败环节、来源和重试动作。

AI 只做摘要、分类和反方解释；事实数值、排名、分数和风险门槛全部由确定性数据与公式产生。AI 不得创建股票代码、新闻事实或缺失的价格。

## 统一页面骨架

新增可复用的 `VisualPageHeader`、`LiveStatusStrip`、`MetricBand`、`ChartPanel`、`EvidenceBadge`、`DataStateNotice`、`RankBarList`、`GaugeRow` 和 `EventKline` 原语。业务页面继续使用独立数据契约，不把所有页面强行做成同一布局。

桌面端默认结构：

```text
页面标题 / 数据截止时间 / 当前来源状态
市场或个股关键指标带
主图表区 + 证据/异动区
专题图表区（按菜单语义选择）
明细表 / 原始证据 / 风险与下一步观察
```

小屏按主图优先、证据其次、明细可横向滚动的顺序单列展示，不通过降低字号解决空间问题。

## 页面迁移顺序

### 第一批：视觉基准页

1. 信息总览：情绪仪表、市场宽度、涨跌停生态、指数分时、异常时间线、板块热力和热门股票表。
2. 今日研判：盘前/盘中/盘后三阶段状态带、市场风格、风险亮点、证据来源和行动纪律。
3. 个股观察：价格摘要、K 线事件、资金流向、风险标签、热点/新闻时间锚点和数据状态。
4. 公司研究：研究总分、证据覆盖、财务五维趋势、估值历史、行业/产品/地区构成和反方审查。
5. 量化分析：市场风格、策略模型、信号投票、Kronos 路径、回测收益风险和候选标签。

### 第二批：市场专题页

首次涨停、连板梯队、首板梯队、板块涨停、炸板、龙虎榜、竞价异动、放量突破、突破前高、低位放量、强度风口、热点播报和复盘统计。每页使用独立的图表组合，不复用无关指标。

### 第三批：数据源与动态能力

接入已经实测可用的通达信 TdxQuant 只读能力：`get_stock_info`、`get_more_info`、`get_ipo_info`、`get_kzz_info` 和 `formula_process_mul_*`。接入前进行能力探测；专业数据包缺失时明确降级。继续禁止交易、账户、撤单和模拟资金功能。

## 动态刷新与启动

- EXE 先展示稳定页面骨架，再按分区渐进加载真实数据。
- 各数据层独立显示“加载中 / 已加载实时最新数据 / 实时监控中 / 部分数据 / 失败环节”。
- 页面可见时按数据层轮询，失焦暂停，重新聚焦立即补刷；所有请求支持取消和标的隔离。
- 启动目标仍为 3 秒内出现首页框架，数据完成后再替换缓存内容，不用假进度冒充真实完成度。

## 验收标准

- 所有菜单页面内容与菜单语义一致，不再以同一套卡片和重复数字应付。
- 所有图表有真实来源、观测时间和数据状态；不出现 `NaN`、`Infinity`、虚构 0 或截图静态数字。
- A 股涨跌严格红涨绿跌；结构组成、来源状态和风险状态使用独立中性/语义色。
- 1440×900、1280×800、390×844 三种视口无遮挡、无横向溢出、核心字号不低于 12px。
- 前端、API、生产构建、乱码扫描和便携 EXE 烟测全部通过。
