# 一树品牌改名设计

## 目标

将软件所有主要用户可见品牌统一为以下文案：

- 左侧品牌名：`一树-A股观测台`
- 软件、窗口和页面标题：`一树电子商务-A股观测台`
- 左侧底部公司名称：`上海一树电子商务有限公司`

公司名称显示在“只做观察与风险提示”上方。

## 范围

修改 React 左侧导航、桌面启动壳、Windows 窗口标题、重复启动窗口查找标题、网页文档标题、FastAPI 展示标题、语音测试文案和 README 品牌标题。

保留 `xiaoqibao.exe`、`XiaoQiBao-Portable`、Python 命令名、单实例 ID、日志文件名及持久目录名称，避免旧快捷方式、数据目录和升级迁移失效。

## 验证

- React 测试验证品牌名、公司名称和底部文案顺序。
- Python 桌面测试验证启动页、窗口标题和重复启动恢复标题。
- 扫描主要用户界面源码，确保旧中文品牌文案不再出现。
- 运行前端全量测试、后端全量测试、生产构建、便携 EXE 重建和真实 EXE 烟测。
