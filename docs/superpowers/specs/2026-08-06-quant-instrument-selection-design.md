# 量化分析标的选择 Design

## 目标

量化分析仪表盘进入后优先恢复全局最近选中的 A 股，并在右上角提供醒目的分析标的卡片，支持六位代码或中文名称查询和切换。

## 设计

- 复用 `SelectedInstrumentProvider` 的 URL 状态。个股观察、公司研究和量化分析共享 `?symbol=`，页面切换后保持同一只股票。
- `Dashboard` 把当前全局标的、股票搜索接口和选择回调传给 `QuantAnalysisDashboard`。
- 新增独立 `QuantInstrumentSelector`，负责当前标的展示、候选池快速切换、代码/名称搜索、加载状态、失败原因和搜索结果选择。
- 量化页优先使用全局标的；全局没有标的时，才回退到首次涨停候选池第一只。
- 自定义股票不在首次涨停候选池时，TICK、历史回测和 Kronos 仍按该股票加载；首次涨停规则因子区明确显示该股未进入候选池，不使用其他股票的因子。
- 所有数据继续来自既有真实接口，不增加模拟行情、模拟因子或默认分数。

## 交互与视觉

- 右上角分析标的区域使用金色强调边框、较大代码和名称，并显示“候选池标的”或“自定义标的”。
- 搜索输入支持六位代码即时查询、中文名称 250ms 防抖查询。
- 查询过程中显示动态加载状态；失败时显示具体错误和重试按钮；无结果时区分数据源不可用与确实无匹配股票。
- 搜索选择与候选下拉切换都会同步全局 URL，重新进入页面时自动恢复。

## 验证

- 组件测试覆盖全局标的优先、无全局标的回退、中文名称搜索、任意 A 股选择、失败提示和候选专属因子边界。
- Dashboard 测试覆盖搜索接口与全局选择状态的接线。
- 完成后运行前端全量测试、生产构建、乱码扫描、便携 EXE 重建和自动烟测。
