# 监控中心提醒测试与菜单顺序设计

## 目标

让用户在监控中心直接验证语音播报和飞书投递是否真正可用，并修复规则卡片操作按钮在不同内容高度下不对齐的问题；同时把监控中心放到“历史复盘”与“数据设置”之间。

## 设计

- 监控中心顶部增加“提醒通道测试”面板，提供独立的“测试语音提醒”和“测试飞书消息”按钮。
- 语音测试复用现有 `/api/v1/speech/synthesize` 实际合成接口，并真实播放返回音频；播放完成、浏览器阻止播放、合成失败分别展示中文结果。
- 飞书测试复用现有 `/api/v1/monitor-center/notification-settings/test` 接口；显示已送达、未配置或后端返回的中文失败原因，不暴露 webhook。
- 规则卡片底部操作区使用固定的 `min-height` 和 `align-self: end`；左侧规则摘要占满剩余空间，右侧状态与操作按钮统一底部对齐，窄屏整体换行。
- 导航顺序改为：……风险提醒、历史复盘、监控中心、数据设置、本地运维；不增加层级和分类。

## 验证

- Web 测试覆盖两个提醒按钮的调用与结果提示、导航相邻顺序、规则卡片操作区结构。
- API 保留现有飞书测试接口回归，并执行语音合成路由回归。
- 生产构建、UTF-8 扫描、EXE smoke 和发布质量门禁必须通过。
