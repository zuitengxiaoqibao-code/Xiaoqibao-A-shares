# 本地行情软件数据源设置设计

## 目标

让便携 EXE 在不依赖固定安装目录的前提下发现和读取本机通达信数据，并允许用户维护多个通达信、券商通达信和同花顺安装目录。未明确配置本地实时桥接时，不访问固定的 `127.0.0.1:17709`，避免每轮刷新产生无效等待。

## 当前问题

- `discover_tdx_vipdoc()` 只检查 `D:/new_tdx_mock/vipdoc` 和 `C:/new_tdx_mock/vipdoc`。
- `Settings` 没有 `tdx_home` 字段，启动代码传入的显式目录始终为空。
- `LocalTdxOverviewSource` 无条件创建 `TdxJsonRpcClient()`，默认访问 `127.0.0.1:17709`。该端口属于可选的额外行情桥接，不是通达信客户端自带能力，也不是 EXE 内部的动态本地 API。
- 设置页只有 AI 和语音设置，无法查看当前采用的本地数据目录或补充其他安装版本。

## 设计决策

### 配置模型

配置保存到便携目录 `config/data-sources.json`，与数据库和缓存分离。模型包含：

- `auto_discovery: bool`，默认开启。
- `tdx_install_paths: list[str]`，按顺序表示手动优先级。
- `ths_install_paths: list[str]`，保存同花顺及券商定制版本目录。
- `tdx_rpc_enabled: bool`，默认关闭。
- `tdx_rpc_url: str | null`，仅允许回环 HTTP 地址，启用桥接时必填。

所有路径必须是本机绝对磁盘路径，不接受 UNC 网络共享。配置采用 UTF-8 JSON、临时文件写入和原子替换。

### 自动发现

自动发现按以下顺序收集并去重：

1. 用户手动配置的目录。
2. 当前运行进程中 `TdxW.exe`、`tdx.exe`、`hexin.exe` 等可识别程序的可执行文件目录。
3. Windows 卸载注册表中的安装位置和显示图标目录。
4. 常见程序目录下的已知产品目录；只做浅层检查，不递归扫描整块磁盘。

通达信目录同时兼容“安装根目录”和直接指向 `vipdoc`。只有同时存在 `sh/lday` 和 `sz/lday` 才能成为本地日线来源。检测结果展示沪深日线文件数量和最新文件日期。

同花顺目录只验证软件是否存在并作为后续适配入口。当前同花顺题材、热点和研报仍使用已核验的公开接口；不能因为检测到本地安装目录就宣称已经读取同花顺本地行情。

### 运行时选择

启动时读取配置并执行发现：

- 第一个验证通过的通达信 `vipdoc` 作为本地日线和情绪因子来源。
- 没有有效本地日线时，继续使用现有已核验仓库和远端行情降级，不生成模拟数据。
- `tdx_rpc_enabled=false` 时不给 `LocalTdxOverviewSource` 创建 RPC 客户端，直接使用现有进程内行情降级链路，不发生 `17709` 连接等待。
- 启用桥接时只接受 `127.0.0.1`、`localhost` 或 `::1`，并使用短连接探测；失败后立即进入降级链路。

保存设置后返回“重新打开软件后生效”。这样避免在运行中替换被多个服务共享的数据源对象，保持线程和缓存契约清晰。

### 设置界面

在“数据设置”首页增加独立的“本地行情软件”区域：

- 自动发现开关。
- 当前采用来源、数据目录、股票文件数、验证状态。
- 通达信目录列表，可增加、删除和调整顺序。
- 同花顺目录列表，明确标记为“已发现，暂未读取本地行情”。
- 本地实时桥接高级开关和地址输入框，默认收起且关闭。
- “重新检测”和“验证并保存”按钮。

路径和状态使用现有 JetBrains Mono、深色终端设计；重要错误用亮红色，验证成功用绿色，待重启状态用金色。页面不展示内部异常堆栈或固定路径假设。

## API

- `GET /api/v1/settings/data-sources`：读取保存配置并返回当前检测结果。
- `POST /api/v1/settings/data-sources/detect`：重新执行自动发现，不写入配置。
- `PUT /api/v1/settings/data-sources`：验证并保存配置，返回检测结果和 `restart_required=true`。

## 失败处理

- 配置文件损坏时回到安全默认值并报告 `invalid_local_config`，不尝试桥接。
- 手动通达信目录不包含有效 `vipdoc` 时返回 422，并指出具体目录。
- 自动发现失败不影响 EXE 启动。
- 同花顺未适配本地数据时保持 `detected_only`，不作为数据质量为 `ready` 的来源。

## 验证

- 单元测试覆盖路径规范化、进程/注册表候选去重、通达信目录验证、原子持久化和回环 URL 限制。
- `LocalTdxOverviewSource` 测试断言未配置 RPC 时零连接尝试。
- 路由测试覆盖读取、检测、保存和无效路径。
- 前端测试覆盖目录增删、重新检测、保存提示和桥接默认关闭。
- 完成后运行 API/Web 全量测试、乱码扫描、便携构建和实际 EXE 烟测。
