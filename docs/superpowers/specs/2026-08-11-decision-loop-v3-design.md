# 真实决策闭环 v3.0 设计规格

日期：2026-08-11  
交付入口：Windows 便携 EXE  
核心原则：真实、可追溯、缓存优先、后台更新、缺失不伪造

## 目标

把现有市场数据、量化策略、公司研究、新闻事件和数据源运维能力连接成一个可持续运行的决策闭环。系统必须先展示最近一次完整真实快照，再在后台刷新；所有结论都能回到来源、观察时间、公式版本和覆盖范围。

## 1. 全市场日线修复中心

现有 `FullMarketHistoryService`、`HistorySyncRepository` 和 `BarRepository` 继续作为唯一日线写入链路。新增修复中心只编排和呈现，不建立第二套日线库。

### 水位定义

- `dominant_trade_date`：全市场有效证券中，最新日线日期出现次数最多的交易日。
- `dominant_date_count`：最新日线等于主导交易日的证券数。
- `history_ready_count`：截至主导交易日至少有 250 根去重日线的证券数。
- `coverage_percent`：`history_ready_count / universe_count * 100`。
- `dominant_date_coverage_percent`：`dominant_date_count / universe_count * 100`。
- `ready`：两项覆盖率均不低于 98%，且没有运行中阻断项。
- `partial`：存在真实数据但未达到就绪门槛。
- `unavailable`：证券池为空或日线库没有有效 A 股记录。

### 修复队列

- 缺失类型固定为：无历史、历史不足 250 根、落后主导交易日、最近任务失败。
- 修复任务使用现有 `backfill` / `incremental` 模式，保持幂等。
- 单股优先通达信/mootdx，失败后才使用百度日线；保留实际来源和安全错误码。
- 连续失败达到阈值自动暂停，禁止无限重试拖慢应用。
- 页面读取状态不得触发同步网络回填。

## 2. 策略影子跟踪账本

每日冻结量化策略候选、市场风格、触发条件、失效条件、建议仓位、证据账本和当时数据截止时间。冻结记录不可覆盖；同一交易日和公式版本重复写入返回已有记录。

### 结果评估

- 仅使用冻结时间之后真实入库的日线评估。
- 评估窗口为 1、3、5、10、20 个交易日。
- 保存区间收益、最大有利变动、最大不利变动、是否触发失效条件和实际可用窗口。
- 缺少未来日线时保持 `pending`，不以 0 代替。
- 汇总只统计已成熟样本，输出命中率、平均收益、盈亏比、最大回撤和样本数。

## 3. API 启动性能

- EXE 窗口目标小于 3 秒出现。
- API 核心健康目标小于 3 秒；重型 provider、全市场扫描和专业能力探测延迟初始化。
- 缓存页面目标小于 1 秒；页面切换 P95 小于 300ms。
- lifespan 只创建轻量仓库、读取配置并注册后台任务，不等待网络、全市场扫描或专业 DLL 探测。
- 后台刷新必须保留旧快照，不能让页面回到整页加载层。

## 4. 公司研究预测时效门槛

- 机构预测结论至少来自 3 家不同机构。
- 每条预测保留机构、报告日期、预测年度、原始指标和来源。
- 最新报告超过 180 天时状态为 `stale`；机构不足时为 `partial`；无真实记录时为 `unavailable`。
- 过期或不足样本不能生成“未来一致预期已确认”类结论。

## 5. 新闻公告与 K 线联动

- 只允许 `verified` 且明确关联当前股票的事件进入个股 K 线。
- 公告与新闻统一为时间线事件，但保留事件种类、来源和关联方式。
- 无法映射到交易日的事件显示在证据列表，不在 K 线上伪造位置。
- 同一事实多源报道聚类展示，保留独立来源数，不重复堆叠标记。

## 6. 数据源健康后台快照

- 健康计算由后台任务定期写入快照；设置页展开时只读快照。
- 快照包含生成时间、统计窗口、成功率、P95 延迟、最后成功时间和最近安全错误码。
- 快照过期时显示 `stale`，不得在 GET 请求中同步探测外部源。

## 7. 通达信专业能力恢复向导

- 向导只做本地只读诊断，不启动、关闭、重启或控制通达信。
- 步骤为：安装目录发现、插件/DLL 发现、进程发现、只读端点可达、能力调用、字段完整性。
- `detected_only` 只表示文件存在；只有返回经过字段校验的真实记录才可 `ready`。
- 普通行情不得冒充 `Fn/GP/BK/SC/GO` 专业字段。

## 状态与证据统一规则

- 状态统一为 `ready / partial / stale / unavailable / error`。
- 每个快照至少包含 `observed_at`、`source`、`formula_version`、`sample_count` 和 `limitations`。
- 禁止随机数据、模拟数据、用 0 填充缺失值、用其他指标代理不可用专业字段。
- A 股行情颜色遵循红涨绿跌；结构、来源和状态使用中性蓝、青、金、紫。

## 验收

- API 与 Web 全量测试通过。
- TypeScript/Vite production build 通过。
- 中文乱码扫描和 UTF-8 检查通过。
- `scripts/build-portable.ps1` 重建便携 EXE，并保留所有持久目录。
- `scripts/run-portable-smoke.ps1 -UseReleaseData` 验证真实发布目录。
- 烟测记录窗口、API、首页、量化、来源健康、日线覆盖、策略账本和通达信进程边界。
