# 信息总览事件呼吸流光设计

## 目标

把事件脉冲轨道当前持续扩散、缩放和悬停位移的动效，改成克制、稳定、适合长时间观看的呼吸流光效果。

## 动效规则

- 事件卡片、编号、标题和轨道位置始终保持静止，不做平移、缩放或自动滚动。
- 普通未选中事件没有循环动画，只保留方向色和静态弱光。
- 当前选中事件每 4.8 秒进行一次低频呼吸：边框、背景亮度和阴影从弱到亮再回落。
- 选中卡片底部使用固定位置的渐变光带，仅改变透明度，不横向滑动。
- 当前异动摘要左侧光点只改变亮度和光晕，不再向外扩散或缩放。
- 悬停仅即时提高边框和背景对比度，不改变卡片位置。
- `prefers-reduced-motion: reduce` 下关闭所有事件区域循环动画和过渡。

## 视觉约束

- 选中态继续使用金色，不改变红涨绿跌方向语义。
- 动效只用于表达“当前选中”，不用于表达涨跌或数据变化。
- 不新增 JavaScript 定时器，不触发 React 重渲染，不影响实时数据刷新性能。

## 验证

- CSS 回归测试确认旧扩散关键帧被移除。
- CSS 回归测试确认事件区域不存在位移或缩放动画。
- CSS 回归测试确认普通卡片不循环、选中卡片才使用低频呼吸。
- Web 聚焦测试、全量测试、生产构建、便携 EXE 烟测通过后交付。
