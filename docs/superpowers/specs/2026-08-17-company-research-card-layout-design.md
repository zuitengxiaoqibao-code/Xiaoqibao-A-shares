# 公司研究账本卡片布局修复设计

## 目标

修复公司研究“十段公司研究账本”在全局折叠三角样式下的网格错位，确保箭头、编号、标题摘要和状态标签始终按固定层级对齐。

## 根因

全局 `details > summary::before` 会为每个折叠标题插入三角伪元素。账本摘要原本声明三列网格，却实际包含四个布局项目，导致标题和状态被自动换行，形成截图中的大面积错位。

## 设计

- 使用显式 `company-research-section-chevron` 元素承载折叠箭头，不再依赖全局伪元素。
- 摘要固定为四列：箭头、编号、标题/摘要、状态。
- 打开状态只旋转箭头，不改变内容层级；每张卡的边界和状态色保持现有语义。
- 宽屏保持两列账本，小屏保持单列；状态标签在小屏标题下方对齐。
- 不改变接口、数据、路由、默认触发项或全局其他折叠组件。

## 验收

- React 测试能确认每张卡存在显式箭头、编号、标题和状态四个直接布局单元。
- 研究账本十项仍全部渲染，触发项仍默认展开。
- 前端测试、生产构建、乱码扫描、`git diff --check` 和便携 EXE smoke 全部通过。
