# A 股关键状态仪表设计

## 目标

在单股分析页顶部提供一个适合新手快速扫读、同时具有专业交易工具信息层级的关键状态仪表。仪表只使用当前系统已有且可验证的数据，不生成虚构风险分或交易概率。

## 页面结构

将“有证据的辅助决策”顶部现有标题、置信度和结论区域重组为四栏仪表：

1. 当前行动：展示加入观察、暂不参与或回避，以及当前确定性结论。分类状态使用语义颜色，不转换成数值。
2. 决策置信度：使用现有 `assessment.confidence`，显示 0-100 圆环仪表。青色表示模型确定程度，不表示收益概率。
3. 证据覆盖率：使用已准备核心数据数除以核心数据总数，显示圆环仪表和可用数据数量。完整为青绿、部分为琥珀、拦截为红色。
4. 个股情绪：使用当前股票已存在的候选情绪分数与区间。没有匹配情绪快照时显示“未评分”，不得用默认值代替。

仪表下方增加一条风险摘要，展示第一条主要风险；若行动为回避或失效，使用红色强提醒。若个股情绪偏积极或过热但当前行动不是“加入观察”，显示“情绪不能覆盖当前风险结论”。

## 视觉规则

- 保持现有深色、紧凑、科学仪器式界面。
- 圆环只用于真实的 0-100 数值；行动和风险保持文字状态。
- 亮青绿表示已验证或积极观察，琥珀表示待确认，亮红表示风险或阻断，青色表示中性信息。
- 不使用渐变背景、发光装饰、动画噪声或嵌套卡片。
- 桌面为稳定四栏；中等屏幕两栏；手机单栏，无横向滚动。

## 数据与降级

- 所有百分比在前端限制到 0-100，非法值显示为不可用。
- 情绪快照必须与当前股票代码一致才能进入仪表。
- 情绪不可用不影响确定性行动结论。
- AI 解释、三阶段状态、检查清单、详细依据和数据详情保持原有数据流与位置。

## 测试

- 验证四个仪表项目及可访问的 `meter` 语义。
- 验证观察、等待、回避的行动颜色类。
- 验证部分数据覆盖率和情绪不可用状态。
- 验证情绪与行动冲突提醒。
- 运行完整前端测试、生产构建、UTF-8/乱码扫描，并检查桌面和手机宽度。
