# 信息总览异动事件稳定快照设计

## 目标

保留分时 K 线的 5 秒刷新，同时让已经显示的异动事件保持稳定，并移除 K 线上方整排事件卡片。

## 展示规则

- 删除“分时事件脉冲轨道”整排卡片，不保留空白占位。
- 保留当前异动摘要、K 线事件编号与右侧异动记录。
- 分时价格、成交量和其他市场数据继续按原 5 秒间隔刷新。
- 同一交易日内，已显示事件的对象、编号、顺序和文字不因背景刷新被替换。
- 后端返回新的真实 `anomaly_id` 时，将新事件追加到稳定快照末尾。
- 后端临时少返回旧事件时，不从当天稳定快照中删除旧事件。
- `as_of` 交易日变化时，清空旧日事件并采用新交易日事件快照。
- 不生成模拟事件，不把新闻或行情变化伪装成新事件。

## 性能

- 使用现有 React 状态和纯数组合并，不新增定时器或网络请求。
- K 线仍使用最新 `minute_series`，事件层使用稳定后的 `anomalies`。

## 验证

- UI 测试确认顶部事件轨道不存在。
- 刷新测试确认旧事件文字、编号和顺序不变，只追加新 ID。
- 跨交易日测试确认旧事件不会带入新交易日。
- Web 全量、production build、便携 EXE smoke 和通达信保护核验通过。
