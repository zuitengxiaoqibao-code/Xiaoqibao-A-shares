## 本轮完成

- 新增本地通达信日线目录指纹监测器，仅只读观察 `.day` 与 `.zip` 文件的路径、大小、修改时间和 SHA-256 内容摘要。
- 首次扫描只建立基线；目录未变化不重复提交导入。
- 文件新增、大小变化或修改时间变化时，复用现有增量导入服务，并交给已有单线程任务执行器。
- 已有手动或自动导入任务处于 pending/running/paused 时，自动监测跳过并显示 `active_job`，避免重复导入。
- 目录读取或任务提交异常显示具体错误，不终止 API 生命周期。
- 运维接口新增 `tdx_auto_import` 状态；运维页显示监测状态、文件数、最近扫描时间、跳过原因和错误原因。
- 自动监测状态只保留当前会话；重启后先重新建立基线，避免把历史状态误认为实时状态。
- 运维诊断摘要默认折叠，可导出为 JSON；导出内容仅含汇总状态，不包含密钥、令牌、密码或原始行情数据。
- 备份创建失败通过安全的用户提示返回，原始异常原因只写入本地运行日志。
