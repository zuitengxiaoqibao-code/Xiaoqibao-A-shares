# 2026-08-19 全站数据日期与新鲜度一致性验证

## 根因

- “首次涨停长期不变”不是页面没有刷新，而是正式数据库只有一条扫描，实际扫描日为 `2026-07-29`，写入时间为 `2026-07-30T01:17:31.871319+00:00`。
- 全市场历史库的主导交易日同样是 `2026-07-29`；`2026-08-18` 只有 1 只股票的零散记录，不能代表完整市场快照。
- 旧实现把查询日期、实际数据日期和生成时间混在一起，导致真实旧缓存在部分菜单中看起来像当前结果。

## 修复后的统一规则

- 历史复盘明确区分查询日期、预期交易日、实际主导交易日、零散最新日期、观测时间和生成时间。
- 完整但落后的市场快照标记为 `stale`；覆盖不足或日期碎片化标记为 `partial`；不可用数据保持 `unavailable`。
- 旧缓存允许继续展示，但必须同时显示真实日期、覆盖率和需要刷新的原因，不得冒充今日数据。
- 首次涨停单独返回查询日期、实际扫描日、扫描更新时间和刷新要求；统计数字与候选明细绑定同一次扫描。
- 信息总览中依赖历史复盘的菜单统一使用同一日期裁决，洞察卡片不会在历史数据过期时继续显示为完整可用。
- 公司研究区分查询日与证据数据截至时间；新闻区分事件发生时间、来源发布时间、归一化时间和分析生成时间。
- 当前交易日盘后扫描不再被旧日期历史回补任务阻断；真实刷新失败时保留旧缓存并展示原因，不生成股票或日期。
