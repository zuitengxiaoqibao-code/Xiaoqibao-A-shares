# 尾盘选股与全站实时数据增量优化验证

## 目标

完成尾盘选股与全站实时数据增量优化，并以真实数据、字段来源、快照审计、性能门禁和 Windows 便携 EXE 作为交付标准。两个工程治理项为：数据质量与可追溯审计、性能与发布回归门禁。

## 完成项

- 尾盘流程按预计算、缩池、实时监控、稳定确认、收盘竞价和冻结分阶段运行。
- 候选保留首次入池、连续确认、触发次数、规则位图、最近变化和失效原因；无真实数据时保持 `partial`、`stale` 或 `unavailable`。
- 慢因子按交易日和股票集合指纹缓存，实时阶段使用最多 300 只真实监控股票，严格匹配项优先保留。
- 共享实时快照总线只推送候选状态、规则位图、冲突或失效等有意义变化；AI 不随每个 tick 重复调用。
- 全站刷新按当前标的、尾盘/异动/新闻、全市场/板块/资金和按需研究分层，页面隐藏时降频。
- 字段级来源仲裁识别过期、冲突和不可用；来源熔断支持连续失败、半开探测和恢复。
- 尾盘快照使用追加式 SQLite 审计，保存输入/输出哈希、公式版本、交易日、观测时间和真实载荷；次日评价只接受严格晚于快照的真实交易日 K 线。
- 发布清单记录尾盘延迟、实时追溯状态、领域状态、启动性能和恢复演练结果。
