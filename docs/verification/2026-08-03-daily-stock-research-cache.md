# 个股观察与公司研究当日缓存验证

## 功能结果

- 个股观察在“行情时间”之前提供醒目的“进入公司研究”按钮，并把当前股票代码写入 `/company-research?symbol=<代码>`。
- 公司研究在“研究时间”之前提供对称的“打开个股观察”按钮，并保留当前股票代码。
- 个股观察和公司研究都展示“今日已加载”缓存记录，包含股票名称、代码和缓存时间；整项可点击并可随时再次进入。
- 个股观察与公司研究按页面、当天和股票代码隔离保存真实 API 完整响应。
- 命中当天缓存时先展示完整旧结果，同时后台请求最新数据。
- 页面显示缓存具体时间、真实请求阶段和进度；最新数据成功后原位替换并更新缓存。
- 最新请求失败时继续展示当天缓存，不退回空白页或错误占位页。
- 公司研究已改用全站终端页面容器、主题变量、JetBrains Mono 和 Orbitron，不再表现为独立配色页面。
- 全局加载状态具备动态扫描反馈；刷新成功显示“已加载实时最新数据 / 当前状态：实时监控中”，失败信息包含失败环节、对象和原因。
- 个股观察的“进入公司研究”按钮首列加宽到 220px，使用更高对比的金色渐变、左侧高亮和发光边界；“同一只股票 · 一键切换”强制单行显示。
- 个股观察刷新状态改为三态：主请求进行中显示“正在载入最新数据”；核心行情已更新但扩展证据仍在补齐时显示“已加载最新可用数据 / 待补齐”；只有准备状态完整后才显示“已加载实时最新数据 / LIVE”，不再与下方“正在补齐数据”自相矛盾。
