## 重要兼容提示

- 官网包清单包含 `requests`，但 FAQ 明确说策略当前不能使用 `requests`；“已安装”不等于“策略运行时允许”。
- 官网包含多种数据库驱动，但 FAQ 限制本地数据库直连。包存在也不代表合规或网络权限已开放。
- Python 3.5 与 3.11 的 NumPy、Pandas、TensorFlow、scikit-learn、statsmodels、TA-Lib 等跨度很大，数值和 API 都需要重新验证。
- 实际环境以研究页 `!pip list` 为最终依据，并保存导出时间和 PTrade 版本。
