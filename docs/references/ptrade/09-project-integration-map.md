# 与本项目的接入地图

## 目标边界

PTrade 最现实的作用是券商环境中的事实数据桥，不是直接替代本地分析系统，也不是立刻打开自动交易。

当前优先级：

1. A 股有效证券池和状态。
2. 全市场历史日线回填。
3. 盘中快照和市场情绪增强。
4. 财务估值证据。
5. 独立可转债基础资料。
6. 有 Level-2 权限后增加短线微观结构信号。
7. 最后才评估人工确认的订单桥。

## 三阶段映射

| 本项目阶段 | PTrade 能力 | 输入事实 | 输出 |
| --- | --- | --- | --- |
| 盘前研判 | `before_trading_start`、`run_daily`、交易日历、证券状态 | 昨日收盘、公告/新闻、状态、财务、候选池 | 市场环境、候选原因、失效条件、风险清单 |
| 盘中监测 | `handle_data`、`get_snapshot`、可选 Level-2 | 价格、量、盘口、涨跌停、交易状态 | 条件触发、证据变化、风险提醒，不自动下单 |
| 盘后复盘 | `after_trading_end`、历史行情、订单/成交核对 | 当日事实、覆盖率、信号结果 | 归因、规则命中率、次日观察池、数据缺口 |

## 数据源状态模型

| 状态 | 含义 |
| --- | --- |
| `documented` | 官网有文档，但未测试账户权限 |
| `configured` | 券商环境已配置，但数据质量未通过 |
| `verified` | 最小样本、字段、时效和覆盖率验证通过 |
| `degraded` | 可用但存在缺失、延迟或部分字段问题 |
| `unavailable` | 无权限、接口失败或不支持当前柜台 |

界面和 AI 解释必须显示真实状态，不能把 `documented` 显示成“数据已连接”。

## 建议导出数据集

| 数据集 | 核心字段 | 建议频率 |
| --- | --- | --- |
| `universe` | 代码、名称、交易所、ST/停牌/退市、交易日 | 每交易日盘前/盘后 |
| `daily_bars` | OHLC、量额、涨跌停、开市标志、复权口径 | 串行批量回填 |
| `snapshots` | 最新价、五档、量额、状态、估值、时间 | 盘中分批轮询 |
| `fundamentals` | 表名、报告期、发布日期、查询日、字段 | 低频缓存 |
| `convertible_bonds` | 转债/正股、转股价、价值、溢价、日期 | 独立数据域 |
| `orders/trades` | 意图、委托、成交、状态和柜台时间 | 仅未来执行阶段 |

## 市场情绪映射

| 本项目因子 | PTrade 事实 |
| --- | --- |
| 波动率情绪 | 日/分钟高低价、昨收、振幅分布 |
| 成交活跃度 | 成交量额、成交笔数、换手率、量比 |
| 价格强度 | 最新价、昨收、涨跌幅、加权均价 |
| 风险偏好 | 市值/估值/板块分组后的涨跌与成交占比 |
| 市场广度 | 全市场上涨、下跌、平盘和有效覆盖 |
| 涨跌停情绪 | 涨跌停价、最新价、交易状态 |
| 赚钱效应 | 个股收益分布、中位数、强势持续性 |
| 板块扩散 | 板块归属、板块快照、板块内上涨比例 |
| 风格偏好 | 市值、估值、行业、指数成分的相对强弱 |

只有在证券池与快照覆盖满足门槛时才计算总分；缺失因子不按 0 分处理，应降低置信度并显示缺口。

## 验证门槛

- [ ] 账户能进入 PTrade 研究环境并确认 Python 版本。
- [ ] `get_Ashares` 返回合理沪深数量。
- [ ] 已知 ST、停牌和退市样本的状态正确。
- [ ] 沪深各样本能返回 300 根合法日线。
- [ ] 完成全市场批量大小、耗时、空响应和重试测试。
- [ ] 盘中快照字段、更新时间和空结果行为验证通过。
- [ ] 转债基础数据权限验证；无权限时不替换现有来源。
- [ ] Level-2 权限明确；未开通时关闭逐笔因子。
- [ ] 导出不包含账号、Cookie、Token 或其他凭据。
- [ ] 本地导入有 schema、校验和、幂等、断点恢复和覆盖率统计。

## 失败处理

1. PTrade 导出失败时保留上一份已验证快照。
2. 数据过期要显示时间，不使用“实时”字样。
3. 与通达信、腾讯、百度冲突时保存各源值和差异，按领域配置主次源。
4. AI 只能解释已经落地的证据，不能用语言模型猜测缺失行情。
5. 所有交易相关功能默认禁用，权限与风控验证不完整时只生成观察建议。
