## Python 环境

- 官方 FAQ 当前说明 Python `3.11.4`。
- 官网页面仍保留 Python 3.5 的 122 个依赖，用于历史策略迁移。
- Python 3.11 页面列出 278 个依赖。
- 完整包名与版本见 `third-party-libraries.md`。
- `check_strategy(strategy_content=None, strategy_path=None)` 可在研究模块检查策略是否涉及升级变动的 API 和 Python 库。

## 3.5 到 3.11 的兼容性主题

官网“三方库变动”重点集中在：

- NumPy 线性代数默认参数变化。
- Pandas 删除或弃用 `join_axes`、`Panel`、`DataFrame.append` 等旧接口。
- Pandas 多个 `to_*`、`resample`、`replace`、`quantile`、`apply`、`sort_index` 的参数、默认值或顺序变化。
- 新版科学计算、机器学习、Jupyter、Web 框架和异步库版本跨度大，历史策略不能只改 Python 版本而不回归测试。

迁移规则：

1. 先用 `check_strategy` 检查已知变动。
2. 固定依赖和策略源代码快照。
3. 对行情读取、复权、DataFrame 索引、缺失值、序列化和指标结果做黄金样本测试。
4. 对 3.5 与 3.11 输出进行字段、行数和数值容差比较。
5. 重新跑完整回测，不沿用旧环境收益结论。
